# clinical_assets_api

🚀 Projeto Novo no Portfólio: Sistema Full-Stack de Gerenciamento Hospitalar!

Nas últimas semanas, mergulhei no desenvolvimento de uma aplicação de ponta a ponta focada em resolver um problema real: o controle de dispositivos médicos por setores de um hospital.

Neste projeto, construí:
✅ Uma API RESTful robusta com Node.js e Express.
✅ Camada de segurança e autenticação utilizando JSON Web Tokens (JWT).
✅ Validação rigorosa de dados no backend com a biblioteca Zod.
✅ Persistência de dados leve e eficiente usando SQLite.
✅ Uma interface web reativa (Front-end) integrada nativamente via Fetch API com manipulação dinâmica do DOM, sem dependência de frameworks complexos.

O maior aprendizado foi lidar com desafios reais de arquitetura, como o gerenciamento de sessões com o localStorage do navegador, tratamento de erros assíncronos e políticas de CORS.

O código está aberto e documentado no meu GitHub! Quem quiser dar uma olhada, criticar ou sugerir melhorias, o link está aqui: [https://github.com/ED-prodogious/clinical_assets_api]

Ainda está incompleto, mas já quero deixar documentado aqui!
